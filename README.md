# 🌊 Lak-Sea Adventures

Welcome to **Lak-Sea Adventures** — a simple static website built using **HTML & CSS**, showcasing scuba diving experiences, packages, and adventures under the sea.

---

## 🚀 Project Overview

This project is a responsive website designed to promote scuba diving activities, highlighting:

- Adventure packages
- Diving locations
- Gallery & testimonials
- Contact details

It provides an engaging and modern design with clean navigation.

---

## 🛠️ Tech Stack

- **HTML5** – Structure of the site
- **CSS3** – Styling and layout
- _(Optional)_ JavaScript – For interactive elements (if added later)

---
